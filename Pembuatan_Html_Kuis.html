Isi data ujian dan soal, lalu unduh satu file HTML ujian yang siap dibagikan ke siswa. Bisa dipakai untuk semua mata pelajaran.

Penilaian

Jawaban diperiksa otomatis dengan kunci. Nilai akhir selalu skala 0–100.

Kata dalam satu baris dianggap sama saat mencocokkan jawaban isian. Huruf besar/kecil, spasi ganda, dan titik di akhir selalu diabaikan. Untuk B. Inggris:

4

Google Sheet (Apps Script)

Hasil, detail jawaban, dan pelanggaran tercatat otomatis di Google Sheet.

  1. Buat Google Sheet baru (ketik sheets.new di browser).
  2. Buka menu Ekstensi → Apps Script, hapus semua isinya, lalu tempel kode dari tombol Copy Apps Script di bawah. Klik ikon simpan.
  3. Klik Terapkan → Penerapan baru. Pilih jenis Aplikasi web, Jalankan sebagai Saya, Yang memiliki akses Siapa saja, lalu Terapkan dan izinkan akses.
  4. Salin URL aplikasi web (berakhiran /exec) dan tempel di kolom di bawah.
